# portfolio-monorepo

# Multi-lingual Portfolio & CMS Monorepo

پروژه‌ی جامع رزومه و پورتفولیو چندزبانه (فارسی، انگلیسی، عربی) به همراه پنل مدیریت اختصاصی.

- **backend**: سرویس RESTful API با NestJS، PostgreSQL و Prisma ORM
- **frontend**: اپلیکیشن Next.js با Tailwind CSS و i18n
- **admin**: پنل مدیریت React (Vite) با ادیتور متنی اختصاصی

### ۱.(Backend)

```bash
cd backend
npm install
npx prisma db push
npm run start:dev
```
